# Portfolio redesign synthesis

## Cross-cutting findings

1. The static head, structured data, noscript copy, 404 page, crawler files, and code comments still identify unrelated template owners. Identity correctness is a prerequisite to visual polish.
2. Project data understates ten substantial repositories with generic filler. Cards should use source-verified descriptions and technologies, with lab/prototype limitations stated honestly.
3. The current skill UI cannot be fixed with CSS alone: 67 technical terms are compressed into one card. A practical L2–L7 operating stack plus a cross-cutting automation rail creates meaningful hierarchy.
4. Employer marks should remain secondary to visible company names. Local, licensed official assets are unavailable, so typographic monograms are the safest production treatment.
5. The existing editorial palette and typography are distinctive and worth preserving. The redesign should replace repetitive cards and decorative hover behavior, not rewrite the whole site.

## Resolutions

- Use native `details/summary` for skill disclosure: keyboard semantics and collapsed focus behavior come for free.
- Treat the generated blueprint artwork as decorative (`alt=""`) because project titles and descriptions already carry the meaning.
- Keep all ten repositories, but give the first four featured visual weight and render the remainder more compactly.
- Use local monogram logo tiles for Northern Trust and Mphasis until approved official logo files are supplied.
- Fix metadata and keyboard defects adjacent to the requested work because leaving them would undermine the redesigned portfolio.
